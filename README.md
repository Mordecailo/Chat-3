# Chat-3

Тестовые страницы, выкладываемые на GitHub Pages.

Адрес сайта: `https://mordecailo.github.io/Chat-3/` (после первого деплоя).

## Локальный запуск

Для быстрой проверки страниц локально:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Деплой

Пуш в ветку `main` автоматически публикует сайт через GitHub Actions.
